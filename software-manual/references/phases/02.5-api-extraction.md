# 阶段 2.5：API 提取

## 优先级

1. 仓库已有且与当前版本一致的 OpenAPI/Swagger JSON 或 YAML。
2. 已运行的本地服务公开的 OpenAPI 端点，但仅在本地访问安全且无需绕过认证时。
3. 项目已经安装和配置的 TypeDoc、pdoc、Swagger 生成器。
4. 静态源码扫描，结果必须标记为启发式。

## 默认命令

```bash
python <skill-dir>/scripts/extract_apis.py \
  --project <repo-root> \
  --output <work-dir>/api-docs
```

该脚本不会安装依赖、启动服务或导入应用模块。它优先解析 OpenAPI JSON，并从常见框架源码生成带文件与行号的候选路由清单。YAML 在无解析库时会被保留并标记为待专用工具验证。

## 运行外部工具前

- 确认工具已存在于项目锁定依赖中。
- 使用项目现有配置，不写入新的依赖或配置文件。
- 先查看 `--help`，将输出定向到工作目录。
- 不导入可能连接数据库、消息队列或外部服务的应用模块。
- 不请求生产令牌，不访问生产管理接口。

## 质量门禁

- 每个端点/函数能追溯到 OpenAPI、公共类型、源码或测试。
- 方法、路径、必填参数、状态码和鉴权不凭空补齐。
- 规范与源码冲突时并列记录，不静默选择。
- 示例值无真实凭据或个人数据。
- 无可靠来源时写“未验证”，并从发布级 API 参考中排除。
